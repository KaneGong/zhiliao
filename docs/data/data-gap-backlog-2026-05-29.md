# 知料数据缺口 Backlog — 供应商 / 法规 / 原料参数

> 日期：2026-05-29
> 阶段：Formula Brief v1 验收闭环后的数据线启动
> 定位：内部执行清单，用于把 Golden Questions、种子案例和供应商资料整理成可持续补库任务。
> 注意：本文件是“待补充 / 待复核”的任务拆分，不等同于法规结论或最终配方建议。

## 1. 为什么现在做这份 backlog

Formula Brief v1 已经能生成结构化方案包，但要从“能演示”变成“更可信、更有商业价值”，核心不是继续堆 UI，而是补齐三类底层资产：

1. **供应商资料**：哪些原料平台能匹配，哪些只能显示“暂无平台匹配”。
2. **法规结构化数据**：普通食品、保健食品、新食品原料、营养强化剂、营养声称边界如何被机器查询。
3. **原料与工艺参数**：添加量、剂型适配、口感、稳定性、货架期、规格书字段等研发信息。

这份 backlog 的目标不是一次性建成大数据库，而是先把最影响 Formula Brief 质量的缺口排优先级。

## 2. 优先级规则

| 优先级 | 判断标准 | 当前处理方式 |
|---|---|---|
| P0 | 影响核心演示、用户高频提问、容易出现合规风险或供应商乱匹配 | 先补结构、字段和首批资料 |
| P1 | 可明显提升方案专业度和商业转化，但不阻塞当前演示 | 排入下一轮补库 |
| P2 | 行业扩展场景，适合后续验证市场需求 | 先记录，不急于深挖 |
| P3 | 长尾品类或暂不确定商业价值 | 暂存，等用户访谈后再决定 |

## 3. 供应商资料 Backlog

### SUP-001 儿童益生菌菌株供应商

- 优先级：P0
- 来源：GQ-003、CASE-003
- 缺口：当前平台暂无核心益生菌菌株供应商匹配。
- 需要字段：菌株编号、适用人群、建议应用品类、活菌数规格、包埋/冻干技术、货架期稳定性、最小起订量、证书、规格书、检测报告。
- 验收：Formula Brief 能明确区分“已有平台供应商”和“暂无平台匹配”，并能列出供应商资料索取清单。

### SUP-002 GABA / 茶氨酸 / 睡前场景原料

- 优先级：P0
- 来源：GQ-001、CASE-001
- 缺口：睡前场景常见原料、软糖剂型适配和苦味遮蔽资料不足。
- 需要字段：原料属性、适用食品类别、建议添加量、口感影响、热稳定性、与软糖工艺兼容性、法规资料链接。
- 验收：避免“助眠/改善睡眠”，同时能给出原料事实、风味和剂型路线。

### SUP-003 透明质酸钠 / 胶原饮辅料

- 优先级：P0
- 来源：GQ-005、CASE-005
- 缺口：透明质酸钠供应商、公告范围、限量和胶原饮风味遮蔽资料需补。
- 需要字段：原料来源、规格、建议添加量、适用剂型、公告/法规依据、供应商证书、风味遮蔽方案。
- 验收：美容类方案不得输出“美容养颜/锁水/抗氧化”等高风险可用表达。

### SUP-004 RTD 蛋白饮与耐酸乳清体系

- 优先级：P1
- 来源：GQ-002、CASE-002、GQ-020
- 缺口：蛋白饮路线已有供应商基础，但低 pH、清爽口感、UHT/货架期稳定体系资料不足。
- 需要字段：蛋白类型、pH 适配、热稳定性、溶解性、黏度、遮蔽方案、典型应用案例。
- 验收：方案能区分 WPC / WPI / 水解乳清 / 牛奶蛋白 / 植物蛋白的应用差异。

### SUP-005 膳食纤维与代餐基料

- 优先级：P1
- 来源：CASE-006、CASE-010、GQ-018
- 缺口：膳食纤维来源、溶解性、胃肠耐受、气泡水稳定性、代餐基料资料不足。
- 需要字段：纤维类型、溶解度、黏度、口感影响、耐酸性、推荐应用场景、营养声称支持字段。
- 验收：能输出“低糖/含膳食纤维/轻负担”，避免“减肥/燃脂/降血糖”。

### SUP-006 植物蛋白与风味遮蔽体系

- 优先级：P1
- 来源：CASE-007、GQ-020
- 缺口：豌豆蛋白、大豆蛋白、米蛋白及砂感/豆腥味遮蔽资料不足。
- 需要字段：蛋白含量、溶解性、颗粒感、风味缺陷、遮蔽方案、烘焙表现、过敏原提示。
- 验收：高蛋白食品方案能兼顾口感、工艺和标签声称条件。

### SUP-007 电解质盐与果冻基料

- 优先级：P1
- 来源：GQ-013、CASE-008
- 缺口：钠/钾/镁来源、果冻凝胶体系、低糖口感和补给场景资料不足。
- 需要字段：矿物质来源、口感咸苦影响、凝胶体系兼容性、低糖甜味体系、包装/便携案例。
- 验收：避免“治疗脱水/快速恢复体能”，输出普通食品补给场景。

### SUP-008 低钠调味与鲜味增强原料

- 优先级：P2
- 来源：GQ-017、CASE-009
- 缺口：氯化钾、酵母抽提物、鲜味肽、复合调味基料资料不足。
- 需要字段：钠含量、钾盐苦味、鲜味增强机制、适用调味品类别、标签声称支持字段。
- 验收：避免“降血压/保护心血管”，聚焦“低钠/鲜味/家庭烹饪”。

### SUP-009 DHA / EPA / 鱼油 / 藻油供应商

- 优先级：P2
- 来源：GQ-011、GQ-012
- 缺口：DHA/EPA 规格、氧化指标、包埋稳定性、儿童适用边界资料不足。
- 需要字段：来源、含量、过氧化值/茴香胺值、包埋工艺、腥味遮蔽、适用食品类别、儿童标签限制。
- 验收：普通食品路径不得输出“提高智力/改善视力/辅助降血脂”等可用表达。

### SUP-010 植物甾醇酯原料

- 优先级：P2
- 来源：GQ-019
- 缺口：新食品原料公告范围、限量、适用食品类别、标签要求和供应商资料不足。
- 需要字段：原料规格、适用产品、每日摄入限制、标签要求、是否适合酸奶体系。
- 验收：普通食品方案必须明确与保健食品路径分流。

### SUP-011 咖啡因能量饮相关原料

- 优先级：P2
- 来源：GQ-014
- 缺口：咖啡因、牛磺酸、B 族维生素、低糖气泡体系和警示语资料不足。
- 需要字段：原料来源、添加范围、标签警示、人群限制、口感遮蔽、渠道审核风险。
- 验收：避免“缓解疲劳/增强精力/提高专注力”等功能承诺。

### SUP-012 饮酒场景原料

- 优先级：P2
- 来源：GQ-015
- 缺口：葛根、枳椇子、维生素等原料属性、适用边界和广告风险资料不足。
- 需要字段：原料属性、可用食品类别、禁用声称、平台审核风险、伦理提示模板。
- 验收：不得输出“解酒/护肝/降低酒精伤害”等可用表达。

## 4. 法规结构化 Backlog

### REG-001 GB 28050 营养声称结构化

- 优先级：P0
- 覆盖：低糖、无糖、高蛋白、低钠、膳食纤维等。
- 目标字段：claim_name、threshold、unit、food_category_scope、calculation_note、source、review_status。
- 对应场景：GQ-002、GQ-013、GQ-017、GQ-018、GQ-020。

### REG-002 GB 14880 营养强化剂可添加范围结构化

- 优先级：P0
- 覆盖：维生素 D、维 C、B 族维生素、钙、镁、DHA 等。
- 目标字段：nutrient、allowed_food_categories、min_max_range、not_allowed_categories、label_note、source、review_status。
- 对应场景：GQ-004、GQ-005、GQ-011、GQ-014、GQ-016。

### REG-003 新食品原料公告结构化

- 优先级：P0
- 覆盖：GABA、透明质酸钠、植物甾醇酯、乳矿物盐等待复核原料。
- 目标字段：ingredient、announcement_no、allowed_scope、daily_limit、excluded_population、label_requirements、source、review_status。
- 对应场景：GQ-001、GQ-004、GQ-005、GQ-019。

### REG-004 普通食品 vs 保健食品声称分流规则

- 优先级：P0
- 覆盖：睡眠、免疫、肠道、骨骼、血脂、血糖、疲劳、护肝、减肥等高风险方向。
- 目标字段：risk_domain、forbidden_expressions、allowed_soft_expressions、needs_health_food_path、example_rewrite。
- 对应场景：所有 Golden Questions。

### REG-005 儿童食品与特殊人群边界

- 优先级：P1
- 覆盖：3 岁以上儿童、婴幼儿、孕妇、老年人、运动人群、饮酒场景用户。
- 目标字段：population、sensitive_terms、category_boundary、label_warning、manual_review_required。
- 对应场景：GQ-003、GQ-011、GQ-016。

### REG-006 渠道话术风险规则

- 优先级：P1
- 覆盖：小红书、直播、电商详情页、招商 PPT、供应商资料页。
- 目标字段：channel、common_risky_terms、safe_rewrite、review_note。
- 对应场景：GQ-005、GQ-014、GQ-015。

## 5. 原料与工艺参数 Backlog

### ING-001 原料参数标准字段

- 优先级：P0
- 目标：先定义所有原料进入平台时必须具备的最小字段。
- 建议字段：ingredient_id、name_cn、name_en、category、function_role、applicable_forms、dosage_range_draft、sensory_notes、solubility、heat_stability、pH_stability、shelf_life_notes、regulatory_flags、supplier_ids、source_links、review_status。
- 验收：后续供应商资料和法规资料能挂到同一原料 ID。

### ING-002 剂型适配参数

- 优先级：P1
- 覆盖：软糖、固体饮料、RTD 饮料、气泡水、酸奶、调味粉、烘焙饼、果冻。
- 目标字段：dosage_form、process_constraints、texture_risks、flavor_risks、stability_risks、common_solutions。
- 验收：Formula Brief 的“配方路线”不只列原料，还能解释为什么适合该剂型。

### ING-003 供应商规格书字段模板

- 优先级：P1
- 覆盖：蛋白、益生菌、胶原、透明质酸钠、DHA/EPA、电解质盐、膳食纤维。
- 目标字段：spec_name、active_content、purity_or_activity、microbiology、heavy_metals、allergens、certificates、coa_required、moq、lead_time。
- 验收：平台能提示用户“下一步要向供应商索取什么资料”。
