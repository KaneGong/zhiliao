## 2. Demo 问题清单

### DEMO-Q-001 高蛋白运动饮 / 蛋白粉

- **推荐使用页面**：`/recommend`
- **问题**：做一款运动后恢复用的高蛋白饮料，目标人群是健身男性，希望口感清爽，蛋白含量有卖点，但成本不能太高。
- **来源**：GQ-002 / DEMO-RC-001
- **预期看点**：能生成 2-3 条配方路线；能区分乳清蛋白、分离乳清蛋白、水解乳清蛋白；能讲清成本、口感、溶解性、稳定性。
- **可能风险**：普通食品不得承诺快速增肌、恢复体能、缓解疲劳；高蛋白和低糖表达要满足营养标签条件。
- **演示备注**：适合作为第一题，成功率高，结构完整，能让观众先看到“方案包”而不是单轮聊天。

### DEMO-Q-002 助眠软糖 / 普通食品边界

- **推荐使用页面**：`/recommend`
- **问题**：开发一款面向办公人群的低糖助眠软糖，需要普通食品可用原料，风味温和，成本可控。
- **来源**：GQ-001 / CASE-001 / DEMO-RC-006
- **预期看点**：系统应主动把“助眠”纠偏为夜间场景、低糖轻负担、风味体验；区分 GABA、茶氨酸、酸枣仁、褪黑素等路径。
- **可能风险**：不得把普通食品写成改善睡眠、助眠、安神、治疗失眠；GABA 和茶氨酸使用范围、用量、人群标签需复核。
- **演示备注**：这题很适合展示“用户说了高风险词，平台不照单全收”。建议后接 DEMO-Q-004 做 GABA 法规速查。

### DEMO-Q-003 儿童益生菌 / 家长可理解但不踩线

- **推荐使用页面**：`/recommend`
- **问题**：开发一款儿童益生菌固体饮料，希望家长容易理解，主打肠道健康和日常营养支持，但不能踩保健食品声称风险。
- **来源**：GQ-003 / CASE-003
- **预期看点**：能避免调节肠道菌群、增强免疫、改善消化等高风险表达；能提示菌株、活菌数、儿童适用年龄、标签复核。
- **可能风险**：核心儿童菌株真实供应商资料仍是缺口；演示时不要把“暂无平台匹配/待索资”解释成平台已有真实供应商。
- **演示备注**：这是“数据缺口透明化”的好题，不建议包装成完美答案。重点展示平台会诚实说需要补菌株资料。

### DEMO-Q-004 GABA 法规查询

- **推荐使用页面**：`/regulations`
- **问题**：GABA（γ-氨基丁酸）能不能用于普通食品？如果做软糖，需要注意哪些边界？
- **来源**：法规库 `GABA（γ-氨基丁酸）` / CASE-001
- **预期看点**：页面应展示数据库命中和简短 AI 解读；能把“可作为新食品原料方向查询”与“不能推导为睡眠功效”分开。
- **可能风险**：法规查询只能说明平台数据库和当前解读，不等于最终产品标签批准；软糖食品类别、使用量、适用人群仍需人工复核。
- **演示备注**：建议紧跟助眠软糖后演示，让观众看到从方案到法规复核的工作流。

### DEMO-Q-005 婴幼儿配方原料 / 乳铁蛋白查询

- **推荐使用页面**：`/regulations`
- **问题**：乳铁蛋白能否用于婴幼儿配方食品？如果用于婴配或特殊膳食食品，需要注意什么？
- **来源**：法规库 `乳铁蛋白`
- **预期看点**：展示法规库对婴幼儿配方、特殊膳食和营养强化剂路径的检索能力；适合补足“婴幼儿配方原料”展示场景。
- **可能风险**：婴幼儿配方属于高敏感食品类别，不能由 AI 直接给最终添加量和标签结论；需要法规专家逐条复核。
- **演示备注**：这是法规页 demo，不建议放到 `/recommend` 生成配方方案。主控可以强调平台先做“法规和资料入口”，不替代注册审评。

### DEMO-Q-006 女性胶原饮 / 渠道话术风险

- **推荐使用页面**：`/recommend`
- **问题**：做一款女性美容方向的胶原蛋白饮，想突出皮肤状态、光泽感和轻负担，渠道主要是小红书和直播电商。
- **来源**：GQ-005 / CASE-005 / DEMO-RC-002
- **预期看点**：能把美容养颜、改善皮肤、锁水、抗衰等高风险话术压住；能给出普通食品可用表达和渠道文案复核点。
- **可能风险**：透明质酸钠、维 C 使用路径和标签要求需复核；直播电商话术容易越界。
- **演示备注**：适合展示“配方 + 合规 + 渠道风险”组合能力。建议后接 DEMO-Q-008 查透明质酸钠。

### DEMO-Q-007 Omega-3 普通食品与保健食品路径分流

- **推荐使用页面**：`/recommend`
- **问题**：做一款成人 Omega-3 补充产品，希望使用鱼油或藻油原料，既想做日常营养补充，也想了解能否表达辅助降血脂等卖点。
- **来源**：GQ-012 / DEMO-RC-005
- **预期看点**：能明确普通食品路径与保健食品路径分流；普通食品不得表达辅助降血脂、保护心血管、预防三高。
- **可能风险**：鱼油、藻油、EPA/DHA 规格和氧化指标需索资；血脂方向卖点必须进入保健食品路径评估。
- **演示备注**：这是“路径分流”最清楚的一题。适合给懂法规或产品策略的人看。

### DEMO-Q-008 透明质酸钠法规查询

- **推荐使用页面**：`/regulations`
- **问题**：透明质酸钠作为食品原料使用时，有哪些使用范围、不适宜人群和标签注意点？
- **来源**：法规库 `透明质酸钠` / CASE-005
- **预期看点**：展示法规页对新食品原料的查询能力；能承接胶原饮中的透明质酸钠风险点。
- **可能风险**：不要把“法规库已收录”理解为任意食品、任意剂量都可用；具体食品类别、推荐食用量和标签仍需复核。
- **演示备注**：适合做法规查询页第二题，和 DEMO-Q-006 形成闭环。

### DEMO-Q-009 儿童 DHA 果味粉 / 成长声称边界

- **推荐使用页面**：`/recommend`
- **问题**：开发一款儿童 DHA 成长营养粉，希望家长能理解 DHA 价值，剂型是果味固体饮料，但不能宣称提高智力、改善视力或提高学习成绩。
- **来源**：GQ-011 / DEMO-RC-008
- **预期看点**：能主动避开提高智力、改善视力、提高学习成绩；能提示 DHA 来源、氧化、腥味、包埋、货架期稳定性。
- **可能风险**：儿童适用年龄、DHA 来源、营养强化路径和标签要求需复核；不能把成长营养写成学习效果承诺。
- **演示备注**：与儿童益生菌搭配，能展示儿童产品的两类边界：菌株合规和成长声称合规。

### DEMO-Q-010 银发日常营养粉 / 供应商价值展示

- **推荐使用页面**：`/recommend`
- **问题**：做一款银发人群日常营养粉，希望支持蛋白补充、骨骼营养和肠道友好，要求冲调方便。
- **来源**：GQ-009 / DEMO-RC-004
- **预期看点**：能展示蛋白、钙、维 D、膳食纤维的组合逻辑；供应商匹配和下一步索资动作较完整。
- **可能风险**：不得宣称治疗骨质疏松、改善骨密度、增强免疫；营养强化剂食品类别和添加量需复核。
- **演示备注**：适合作为收尾题，展示平台从创意、配方、合规到采购资料动作的完整闭环。

## 3. 数据缺口与演示提醒

| 缺口 | 影响场景 | 演示处理方式 |
|---|---|---|
| 儿童益生菌真实菌株供应商未完成索资 | DEMO-Q-003 | 明确说这是数据透明化样例，不把占位或线索说成真实供应商 |
| GABA / 茶氨酸软糖供应商和工艺资料仍需补 | DEMO-Q-002 / DEMO-Q-004 | 强调当前可演示法规边界和询样动作，非最终配方 |
| 婴幼儿配方原料属于高敏感类别 | DEMO-Q-005 | 只走 `/regulations` 查询，不建议现场生成婴配配方 |
| 透明质酸钠、DHA、Omega-3 等原料需复核使用范围 | DEMO-Q-006 / 007 / 008 / 009 | 把“需法规复核”作为平台可信度看点 |
| 法规查询结果不是法律意见 | 所有 `/regulations` demo | 结尾提醒“仅供参考，不构成法律建议”，需人工复核 |
