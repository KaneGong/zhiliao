# 知料 Demo Question Set v2

> 日期：2026-06-03  
> 用途：Public Evidence 扩展到 30 张原料证据卡后的新版演示题单，供主控在 `/recommend` 和 `/regulations` 页面快速展示“配方方案 + 法规路径 + 风险边界 + 未收录待复核”能力。  
> 继承：`docs/data/demo-question-set-v1.md`。  
> 数据基础：Public Evidence v1 当前为 30 ingredient cards / 7 regulatory paths / 21 sources。  
> 边界：本文件只做 demo 题单和演示口径，不新增供应商数据，不代表最终法规结论或商业承诺。Public Evidence 不等于 Supplier Verified。

## 1. v2 更新重点

相比 v1，本版重点从“网站基础展示”升级为“公开证据库能力展示”：

1. **新增第二批 Public Evidence 原料场景**：咖啡因、牛磺酸、B6、镁、钾盐、聚葡萄糖、抗性糊精、赤藓糖醇、葛根、枳椇子。
2. **更适合现场演示的高风险题**：能量饮、饮酒场景软糖、低钠调味粉、电解质果冻、膳食纤维气泡水。
3. **演示口径更明确**：AI 不应给“合规无忧/已验证供应商/确定功效”式结论；应给可打样研发路线，同时把法规、标签、用量、供应商索资列为待复核。
4. **更适合主控使用**：每题都写清楚推荐页面、预期看点、红线、主控话术和答案偏保守时的解释方式。

## 3. Demo 问题清单

### DEMO2-Q-001 高蛋白运动饮 / 正向样板

- **推荐使用页面**：`/recommend`
- **问题**：做一款运动后日常补充用的高蛋白饮料，目标人群是健身男性，希望口感清爽，蛋白含量有卖点，但成本不能太高。
- **预期看点**：
  - 输出 2-3 条清晰配方路线。
  - 区分乳清蛋白、豌豆蛋白、大豆分离蛋白等原料路径。
  - 能讨论口感、溶解性、稳定性、成本和供应商索资点。
- **高风险红线**：不得承诺快速增肌、治疗疲劳、恢复体能；高蛋白/低糖表达需要满足营养标签条件。
- **主控话术**：这题用于展示知料不是单纯聊天，而是把“产品定位、原料方案、工艺风险、合规提醒、下一步索资”合成一个研发工作台输出。
- **如果答案偏保守**：可以解释为普通食品场景下不能替用户直接做功效承诺，但仍应给可打样路线。

### DEMO2-Q-002 办公人群夜间场景软糖 / 合规纠偏

- **推荐使用页面**：`/recommend`
- **问题**：开发一款面向办公人群的低糖助眠软糖，需要普通食品可用原料，风味温和，成本可控。
- **预期看点**：
  - 主动把“助眠”纠偏为夜间场景、放松时刻、低糖轻负担、风味体验。
  - 区分 GABA、茶氨酸、酸枣仁、褪黑素等不同路径。
  - 提醒普通食品不能做改善睡眠、治疗失眠、安神等表达。
- **高风险红线**：不得直接建议普通食品宣称助眠、改善睡眠、安神、治疗失眠；具体用量和食品类别需复核。
- **主控话术**：这题最适合展示“用户提出高风险需求，平台不会照单全收，而是自动降风险并保留研发方向”。
- **如果答案偏保守**：这是合理的，重点不是让 AI 乱承诺，而是让 AI 帮研发团队先避坑。

### DEMO2-Q-003 GABA 法规查询 / 证据追溯

- **推荐使用页面**：`/regulations`
- **问题**：GABA（γ-氨基丁酸）能不能用于普通食品？如果做软糖，需要注意哪些边界？
- **预期看点**：
  - 命中 Public Evidence 原料卡。
  - 区分“作为食品原料路径可讨论”和“不能推导为睡眠功效”。
  - 明确提醒使用范围、推荐食用量、不适宜人群和标签需要人工复核。
- **高风险红线**：不得把证据卡解释成最终标签批准；不得把 GABA 直接等同于助眠功效。
- **主控话术**：推荐紧跟 DEMO2-Q-002 展示，形成“配方创意 → 法规证据复核”的工作流闭环。
- **如果答案偏保守**：法规查询的价值就是把不确定性显性化，不是替代法规专家出最终结论。

### DEMO2-Q-004 咖啡因能量饮 / 提神与能量声称边界

- **推荐使用页面**：`/recommend`
- **问题**：做一款年轻白领下午喝的低糖能量饮，希望有咖啡因和牛磺酸，口感清爽，想表达提神、专注和抗疲劳，但要尽量走普通食品路径。
- **预期看点**：
  - 命中咖啡因、牛磺酸、维生素 B6 等 Public Evidence 卡。
  - 能主动区分普通食品表达和保健食品/功能声称路径。
  - 给出低糖、酸甜口、气泡或非气泡等产品路线。
- **高风险红线**：普通食品不得承诺抗疲劳、提升专注力、提高工作效率、改善精神状态等功能结果；咖啡因相关警示和人群标签需复核。
- **主控话术**：这题展示知料能处理“市场想要的卖点”和“法规可表达边界”之间的冲突。
- **如果答案偏保守**：可以说明能量饮本身就是高风险表达区，平台宁可保守，也不应鼓励越界营销。

### DEMO2-Q-005 饮酒场景软糖 / 解酒护肝红线

- **推荐使用页面**：`/recommend`
- **问题**：做一款聚会前后吃的软糖，想加入葛根、枳椇子和维生素 C，用户希望减少第二天不适，但我们不想踩解酒护肝的法规风险。
- **预期看点**：
  - 命中葛根、枳椇子、维生素 C 证据卡。
  - 能把“解酒、护肝、醒酒、降低酒精伤害”降级为聚会场景、口感补充、轻负担等普通食品表达。
  - 给出原料采购和法规复核清单。
- **高风险红线**：不得宣称解酒、护肝、降低酒精吸收、保护肝脏、缓解宿醉；不得暗示可以减少饮酒风险。
- **主控话术**：这题是展示“高风险词识别和表达重写”的强演示题。系统应该可以继续给产品路线，但必须压住功效承诺。
- **如果答案偏保守**：这是预期结果。饮酒相关场景尤其不能让用户误以为食品能抵消酒精危害。

### DEMO2-Q-006 儿童益生菌固体饮料 / 菌株证据缺口

- **推荐使用页面**：`/recommend`
- **问题**：开发一款儿童益生菌固体饮料，希望家长容易理解，主打日常肠道友好和营养支持，但不能踩保健食品声称风险。
- **预期看点**：
  - 能提示儿童产品需要关注菌株编号、活菌数、适用年龄、标签和稳定性。
  - 不把平台未索资菌株说成已验证供应商。
  - 能给出口味、剂型、包装和下一步资料清单。
- **高风险红线**：不得宣称调节肠道菌群、增强免疫、改善消化、治疗便秘腹泻等保健或医疗化表达。
- **主控话术**：这题不是展示“完美答案”，而是展示系统会诚实指出儿童菌株资料和供应商索资缺口。
- **如果答案偏保守**：儿童产品本来就应更保守。能透明标注待复核，比给确定性结论更可信。

### DEMO2-Q-007 电解质果冻 / 运动补给但不医疗化

- **推荐使用页面**：`/recommend`
- **问题**：做一款运动后吃的电解质果冻，含钠、钾、镁和维生素 B6，适合夏天户外运动人群，想强调补水和快速恢复。
- **预期看点**：
  - 命中钾盐、镁、维生素 B6 等证据卡。
  - 能把“快速恢复、治疗脱水、抗疲劳”降级为运动后水分与矿物质补充场景。
  - 能提示营养强化剂使用范围、添加量、营养标签和口感稳定性复核。
- **高风险红线**：不得宣称治疗脱水、快速恢复体能、抗疲劳、改善抽筋等功能结果。
- **主控话术**：这题展示系统能处理运动食品常见表达，把研发方向保留下来，但不越过普通食品边界。
- **如果答案偏保守**：说明系统在把医疗化和功能化表达拉回普通食品语境。

### DEMO2-Q-008 低钠调味粉 / 钾盐替代和标签边界

- **推荐使用页面**：`/recommend`
- **问题**：开发一款低钠调味粉，想用氯化钾或柠檬酸钾替代部分食盐，面向控盐人群，口感不能有明显苦味。
- **预期看点**：
  - 命中钾/氯化钾/柠檬酸钾证据卡。
  - 讨论低钠表达、钠含量条件、钾盐风味、复配遮味。
  - 提醒特殊人群和标签注意。
- **高风险红线**：不得宣称降血压、治疗高血压、保护心血管；低钠声称必须满足营养标签条件。
- **主控话术**：这题适合展示“法规 + 产品工程”的结合：不是只会说不能做，也会给出味觉和工艺解决方向。
- **如果答案偏保守**：钠/钾涉及特殊人群风险，谨慎是正确的。

### DEMO2-Q-009 膳食纤维气泡水 / 低糖和肠道表达边界

- **推荐使用页面**：`/recommend`
- **问题**：做一款低糖膳食纤维气泡水，想用聚葡萄糖、抗性糊精、赤藓糖醇，口感清爽，希望表达轻负担和肠道友好。
- **预期看点**：
  - 命中聚葡萄糖、抗性糊精、赤藓糖醇证据卡。
  - 能讨论膳食纤维含量、甜味口感、耐受性、气泡稳定性。
  - 能区分“膳食纤维来源/轻负担”与“改善便秘/调节肠道菌群”等高风险表达。
- **高风险红线**：不得宣称改善便秘、调节肠道菌群、减肥、控糖；低糖/无糖/膳食纤维声称需满足营养标签条件。
- **主控话术**：这是第二批证据卡中最适合普通消费者理解的题，适合给不懂法规的人看。
- **如果答案偏保守**：低糖和肠道方向很容易变成功效宣称，保守是平台可信度的一部分。

### DEMO2-Q-010 透明质酸钠 / 乳铁蛋白 / DHA 专项法规查询

- **推荐使用页面**：`/regulations`
- **问题 A**：透明质酸钠作为食品原料使用时，有哪些使用范围、不适宜人群和标签注意点？
- **问题 B**：乳铁蛋白能否用于婴幼儿配方食品？如果用于婴配或特膳，需要注意什么？
- **问题 C**：DHA 藻油和鱼油 Omega-3 做普通食品或儿童产品时，需要注意哪些法规边界？
- **预期看点**：
  - 展示法规页可做原料级证据查询。
  - 能区分新食品原料、婴幼儿/特膳、营养强化剂、普通食品、保健食品等路径。
  - 对高敏感品类明确提示人工复核。
- **高风险红线**：不得输出任意剂量、任意食品类别均可使用；不得替代注册审评或法规专家意见。
- **主控话术**：这是 v2 演示的法规收尾题，让观众看到系统不只是生成创意，也能进入证据和路径判断。
- **如果答案偏保守**：法规页应保守，尤其婴幼儿、DHA、透明质酸钠都需要具体类别和标签条件复核。
