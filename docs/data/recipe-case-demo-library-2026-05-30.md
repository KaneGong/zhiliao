## 1. 选择原则

从现有 20Q 中优先选择适合对外 demo 的案例，而不是优先选择最需要补数据的案例：

1. **结构稳定**：20Q 回归中有结构化 brief、routes、checks、verification、SSE DONE。
2. **业务分数高**：优先选人工评分 9-10 分，最低不低于 8 分。
3. **可演示度高**：能展示 Formula Brief 的路线拆解、法规边界、供应商/索资价值、下一步动作。
4. **风险可控**：高风险声称能被明确压住；如涉及儿童/美容/Omega-3/更年期等，只作为“风险边界 demo”。
5. **不依赖未索资供应商**：如果真实供应商资料未完成，只写“需索资 / 需复核”，不新增 `src/data`。

## DEMO-RC-001 清爽高蛋白运动饮

- **source_gq**：GQ-002
- **status**：demo_draft
- **quality_score**：90/100
- **scenario_tags**：运动营养、高蛋白、清爽口感、成本控制、RTD/固体饮料
- **target_user**：健身男性、轻运动人群、运动后蛋白补充用户。
- **product_format**：RTD 蛋白饮 / 固体饮料。
- **regulatory_path**：普通食品优先。
- **positioning**：一款以蛋白补充和清爽口感为核心的运动后营养饮，展示成本优先与效果优先路线的取舍。
- **consumer_job**：运动后想补充蛋白，但不希望饮品厚重、甜腻或成本过高。

### Formula Routes

1. **保守成本路线**：WPC + 甜味/酸味体系，适合成本敏感和固体饮料起步。
2. **主流清爽路线**：WPI / 水解乳清蛋白 + 酸味水果风味，适合高蛋白卖点和清爽口感。
3. **创新高端路线**：水解蛋白 + 电解质/低糖体系，适合运动后补给场景，但需更强工艺验证。

### Core Ingredients

| 原料 | 配方角色 | 平台/法规状态 | 复核点 |
|---|---|---|---|
| 乳清蛋白 / 分离乳清蛋白 | 核心蛋白来源 | 平台已有蛋白类线索，仍需按具体型号索资 | 蛋白含量、溶解性、热稳定、乳过敏原 |
| 水解乳清蛋白 | 清爽度和吸收场景差异化 | 需按供应商资料确认 | 苦味、成本、标签表达 |
| 低糖甜味体系 | 口感和营养标签 | 需满足营养标签条件 | 低糖/无糖表达、后味 |

### Compliance Boundaries

- **可用表达**：高蛋白、运动后蛋白补充、清爽口感、低糖（满足条件后）。
- **禁用/不建议表达**：快速增肌、恢复体能、缓解疲劳、提高运动表现。
- **需复核**：蛋白质含量声称、低糖声称、乳过敏原、RTD 杀菌稳定性。

### Supplier Match Logic

- 可演示“已有蛋白方向供应商线索 + 需索取具体规格”的工作流。
- 不在本文件新增供应商；索资重点为规格书、COA、溶解性、热稳定、推荐添加量、饮料应用案例。

### Risk Points

- 高蛋白 RTD 可能出现沉淀、絮凝、热稳定问题。
- 清爽口感与蛋白含量、成本之间存在冲突。
- 运动场景容易滑向“恢复体能/缓解疲劳”声称。

### Next Steps

1. 确认 RTD 与固体饮料两个剂型的优先级。
2. 向蛋白供应商索取饮料级规格、热稳定和感官建议。
3. 打样对比 WPC / WPI / 水解蛋白路线。
4. 法规复核高蛋白、低糖、运动场景话术。

## DEMO-RC-002 女性轻负担胶原饮

- **source_gq**：GQ-005
- **status**：demo_draft
- **quality_score**：90/100
- **scenario_tags**：女性营养、胶原饮、透明质酸钠、直播电商、小红书风险
- **target_user**：年轻女性、轻养生用户、直播电商和内容种草渠道用户。
- **product_format**：瓶装风味饮料 / 条包固体饮料。
- **regulatory_path**：普通食品优先；涉及透明质酸钠和维 C 使用路径需复核。
- **positioning**：一款用原料事实、口感和轻负担构建差异化的胶原饮，不承诺改善皮肤。
- **consumer_job**：希望获得“日常饮用 + 好喝 + 有原料故事”的轻美容方向饮品。

### Formula Routes

1. **保守胶原路线**：胶原蛋白肽 + 果味低糖体系，上市快、风险低。
2. **主流复配路线**：胶原蛋白肽 + 透明质酸钠 + 维 C，卖点强但法规复核要求高。
3. **创新渠道路线**：胶原三肽 / 高端胶原原料 + 清爽瓶装饮，适合直播电商，但话术风险最高。

### Core Ingredients

| 原料 | 配方角色 | 平台/法规状态 | 复核点 |
|---|---|---|---|
| 胶原蛋白肽 | 主卖点和蛋白原料事实 | 平台已有胶原方向线索 | 来源、分子量、腥味、溶解性 |
| 透明质酸钠 | 差异化原料 | 已作为 Package 2 seed，需公告边界复核 | 食用范围、不适宜人群、推荐食用量、标签提示 |
| 维生素 C | 营养协同 / 酸味体系 | 需区分营养强化剂或其他使用路径 | GB 14880 食品类别、添加量、标签表达 |

### Compliance Boundaries

- **可用表达**：添加胶原蛋白肽、清爽低糖、日常饮用、果味胶原饮。
- **禁用/不建议表达**：美容养颜、改善皮肤、锁水、补水、抗衰、逆龄、水光肌。
- **渠道复核**：小红书、直播电商、达人话术需单独负面词表。

### Supplier Match Logic

- 展示“已有胶原方向 + 透明质酸钠需索资”的组合逻辑。
- 不新增未索资供应商；真实候选需提供透明质酸钠公告适配和胶原肽感官资料。

### Risk Points

- 内容渠道容易将普通食品写成功效产品。
- 透明质酸钠有不适宜人群、食用量和标签提示复核要求。
- 胶原肽腥味和酸性饮料稳定性影响复购。

### Next Steps

1. 准备小红书/直播禁用词与替代表达表。
2. 向胶原和透明质酸钠供应商索取规格、COA、应用案例。
3. 做低糖果味打样，重点测试腥味和后味。
4. 法规复核透明质酸钠和维 C 使用路径。

## DEMO-RC-003 高蛋白办公室零食棒

- **source_gq**：GQ-008
- **status**：demo_draft
- **quality_score**：90/100
- **scenario_tags**：高蛋白零食、办公室、运动后、低糖、质构
- **target_user**：办公室人群、运动后补充用户、希望低甜度和饱腹感的人群。
- **product_format**：蛋白棒 / 软质零食棒。
- **regulatory_path**：普通食品优先。
- **positioning**：一款兼顾高蛋白、低甜度和不粉不硬口感的办公室补充型零食棒。
- **consumer_job**：想在办公室或运动后快速补充营养，同时避免传统蛋白棒过甜、过硬、粉感重。

### Formula Routes

1. **保守乳清路线**：乳清蛋白 + 糖醇/膳食纤维 + 坚果谷物基底，成本和供应链成熟。
2. **主流复配路线**：乳清蛋白 + 牛奶蛋白 + 胶原蛋白，兼顾质构、蛋白含量和咀嚼感。
3. **创新低糖路线**：蛋白复配 + 可溶性纤维 + 保湿体系，强调低糖和柔软货架期。

### Core Ingredients

| 原料 | 配方角色 | 平台/法规状态 | 复核点 |
|---|---|---|---|
| 乳清蛋白 / 牛奶蛋白 | 蛋白来源 | 平台已有蛋白类线索 | 吸水性、颗粒感、硬化趋势 |
| 胶原蛋白 | 质构辅助与蛋白补充 | 需按具体供应商资料确认 | 胶原来源、腥味、成本 |
| 膳食纤维 / 糖醇 | 低糖和质构 | 需标签条件复核 | 低糖声称、胃肠耐受、后味 |

### Compliance Boundaries

- **可用表达**：高蛋白、低糖、办公室零食、运动后蛋白补充。
- **禁用/不建议表达**：快速增肌、减脂、代谢提升、燃脂。
- **需复核**：蛋白质声称、低糖声称、过敏原、糖醇耐受提醒。

### Supplier Match Logic

- 适合展示“蛋白原料 + 质构/货架期索资”的采购工作流。
- 不新增供应商；索资重点为蛋白粉粒径、吸水性、棒类应用案例、保湿体系建议。

### Risk Points

- 高蛋白棒常见问题是硬化、粉感、甜味后苦和货架期质构劣变。
- 低糖体系可能带来胃肠耐受和后味问题。
- 健身渠道文案容易滑向增肌/减脂。

### Next Steps

1. 做乳清/牛奶蛋白/胶原三种复配比例小试。
2. 记录 0/15/30 天质构变化。
3. 索取蛋白棒应用规格和推荐添加量。
4. 复核高蛋白、低糖和糖醇标签要求。

## DEMO-RC-004 银发日常营养粉

- **source_gq**：GQ-009
- **status**：demo_draft
- **quality_score**：90/100
- **scenario_tags**：银发营养、蛋白补充、骨骼营养、肠道友好、冲调便利
- **target_user**：银发人群、中老年家庭、希望日常补充蛋白和基础营养的人群。
- **product_format**：固体饮料 / 营养粉。
- **regulatory_path**：普通食品优先；营养强化剂使用需按食品类别复核。
- **positioning**：一款适合银发人群日常冲调的蛋白、钙维 D 和膳食纤维组合营养粉。
- **consumer_job**：帮助家庭用更方便的方式为老人做日常营养补充，而不是治疗疾病。

### Formula Routes

1. **保守高蛋白路线**：乳清蛋白 / 牛奶蛋白 + 低糖风味，强调冲调和蛋白补充。
2. **主流骨骼营养路线**：蛋白 + 钙源 + 维生素 D，强调基础营养协同。
3. **创新肠道友好路线**：蛋白 + 膳食纤维 / 益生元，强调冲调顺滑和日常轻负担。

### Core Ingredients

| 原料 | 配方角色 | 平台/法规状态 | 复核点 |
|---|---|---|---|
| 乳清蛋白 / 牛奶蛋白 | 蛋白补充 | 平台已有蛋白类线索 | 溶解性、乳糖不耐受、过敏原 |
| 钙源 / 乳矿物盐 | 骨骼营养事实 | 需按原料属性和公告复核 | 食品类别、添加量、沉淀 |
| 维生素 D | 营养强化 | 需 GB 14880 复核 | 食品类别、添加量、标签 |
| 膳食纤维 / 益生元 | 口感和肠道友好场景 | 需标签和耐受复核 | 冲调黏度、胃肠耐受 |

### Compliance Boundaries

- **可用表达**：蛋白补充、高钙/含钙（满足条件后）、含维生素 D、日常营养粉、冲调方便。
- **禁用/不建议表达**：改善骨密度、预防骨质疏松、治疗关节疼痛、增强免疫。
- **需复核**：营养强化剂食品类别、老年人适用性、乳糖不耐受提示。

### Supplier Match Logic

- 可展示“供应商匹配较强 + 仍需规格索资”的正向样板。
- 不新增供应商；重点索取蛋白、钙源、维 D、纤维在粉剂中的冲调和稳定资料。

### Risk Points

- 老年场景容易疾病化。
- 高蛋白与钙源可能造成冲调粉感或沉淀。
- 维 D 和钙强化需严格匹配食品类别和用量。

### Next Steps

1. 先确定普通食品营养粉路径，不写疾病承诺。
2. 做冲调口感、沉淀、甜度和黏度小试。
3. 索取钙源/蛋白/维 D 的规格和适用食品类别说明。
4. 法规复核营养强化和标签表达。

## DEMO-RC-005 成人 Omega-3 路径分流案例

- **source_gq**：GQ-012
- **status**：demo_draft
- **quality_score**：92/100
- **scenario_tags**：Omega-3、鱼油、藻油、普通食品、保健食品路径分流
- **target_user**：成人营养补充用户、关注 Omega-3 原料和表达路径的品牌方。
- **product_format**：软胶囊 / 微囊粉 / 饮品方向待确认。
- **regulatory_path**：普通食品与保健食品路径分流。
- **positioning**：一个用于展示“同一原料方向，不同法规路径导致完全不同表达”的路径分流案例。
- **consumer_job**：既想做日常营养补充，又想了解能不能表达辅助降血脂等卖点。

### Formula Routes

1. **普通食品路线**：鱼油或藻油来源 Omega-3，表达原料事实和日常营养补充。
2. **保健食品评估路线**：如要表达血脂方向，进入保健食品注册/备案评估。
3. **素食差异化路线**：DHA 藻油或微囊粉，面向素食和轻补充人群。

### Core Ingredients

| 原料 | 配方角色 | 平台/法规状态 | 复核点 |
|---|---|---|---|
| 鱼油 / 鱼油及提取物 | Omega-3 来源 | Package 2 已有 seed，需真实索资 | EPA/DHA 规格、氧化指标、污染物 |
| DHA 藻油 | 素食来源和儿童/成人差异化 | Package 2 已有 seed，需公告边界复核 | 来源、质量指标、适用食品类别 |
| 微囊粉 / 乳化体系 | 剂型适配 | 需供应商应用资料 | 返味、氧化、分散性 |

### Compliance Boundaries

- **普通食品可用表达**：日常脂质营养补充、添加鱼油或藻油来源 Omega-3、EPA/DHA 规格以检测为准。
- **普通食品禁用表达**：辅助降血脂、降血脂、保护心血管、预防三高。
- **保健路径提示**：如要使用血脂/心血管方向卖点，应单独走保健食品路径评估。

### Supplier Match Logic

- 适合展示“供应商规格索取清单”：EPA/DHA 含量、过氧化值、茴香胺值、重金属、食品级资质、剂型适配。
- 不新增未索资供应商；真实候选已放入 Package 3 供应商候选表。

### Risk Points

- 普通食品和保健食品表达边界容易混淆。
- 油脂氧化、腥味、返味和货架期是核心工艺风险。
- 慢病人群联想强，渠道文案必须严格控制。

### Next Steps

1. 先选择普通食品还是保健食品路径。
2. 向鱼油/藻油供应商索取 EPA/DHA 和氧化指标资料。
3. 对比软胶囊、微囊粉、饮品乳化路线。
