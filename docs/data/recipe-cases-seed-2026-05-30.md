## 0. 共同审核规则

- 普通食品路径下，不输出“改善睡眠、增强免疫力、辅助降血糖、减肥、美容、增加骨密度、治疗/预防疾病”等保健功能或疾病表达作为可用声称。
- 新食品原料、营养强化剂、可用于食品菌种、保健食品原料目录原料必须按具体公告/标准复核食品类别、使用量、适用人群和标签要求。
- 平台已有匹配来自当前 `src/data/ingredients.json` 初步检索；只代表“可询样/可补资料”的线索，不代表已确认可用于该配方。
- 每条案例都要索取供应商规格书、COA、过敏原、适用食品类别声明、稳定性/工艺建议和推荐添加范围。

## RC-20260530-001 办公人群夜间轻负担软糖

- **状态**：draft
- **质量评分初估**：78/100
- **场景标签**：助眠场景、低糖、软糖、普通食品边界、办公人群
- **目标人群**：25-40 岁办公人群，晚间想要放松仪式感，关注低糖和温和风味。
- **剂型**：低糖果胶软糖 / 凝胶糖果。
- **法规路径**：普通食品优先；如要直接宣称“改善睡眠”需另行评估保健食品路径。
- **产品定位**：夜间轻负担的放松场景软糖，而不是“助眠功效”产品。

### Formula Routes

1. **保守路线：风味仪式感软糖**
   - 核心原料：果胶/明胶凝胶体系、赤藓糖醇或其他低糖甜味体系、茶香/花果香风味、膳食纤维类填充。
   - 角色：低糖口感、夜间消费场景、咀嚼仪式感。
   - 成本等级：低-中。
   - 工艺注意：低糖体系会影响凝胶强度和水活度；需测试返砂、析水、粘牙和包装防潮。
   - 主要风险：营销端容易把“夜间放松”写成“助眠/改善睡眠”。

2. **主流路线：GABA 场景软糖**
   - 核心原料：GABA（γ-氨基丁酸）、低糖甜味体系、酸甜风味、可选膳食纤维。
   - 角色：差异化认知原料、夜间场景记忆点。
   - 成本等级：中。
   - 工艺注意：需确认 GABA 在软糖加工温度、pH 和货架期中的稳定性。
   - 主要风险：GABA 属新食品原料，必须复核公告中的使用范围、每日用量、适用人群和标签要求；不得直接推导为睡眠功效。

3. **创新路线：乳肽放松场景软糖**
   - 核心原料：酪蛋白水解肽概念原料、温和奶香/香草风味、低糖软糖基底。
   - 角色：差异化原料故事、温和风味。
   - 平台候选：`ING-LAC Lactium 酪蛋白水解肽`（需供应商确认适用食品类别、添加建议和标签边界）。
   - 成本等级：高。
   - 主要风险：功能联想强，普通食品表达要保守；乳源过敏原提示。

### 核心原料与平台匹配

| 原料 | 角色 | 平台匹配 | 法规/边界 | 是否需复核 |
|---|---|---|---|---|
| GABA（γ-氨基丁酸） | 场景认知原料 | 暂无平台产品匹配 | 法规库已收录：新食品原料；按公告复核 | 是 |
| 酪蛋白水解肽 | 差异化乳肽 | `ING-LAC Lactium` / Ingredia 安迪亚 | 乳源原料，普通食品不得宣称改善睡眠 | 是 |
| 膳食纤维/低聚糖 | 口感、低糖填充 | `CLA-BGOS Bimuno GOS` 可作为益生元方向线索 | 低聚半乳糖等需复核新食品原料公告范围 | 是 |

### 合规边界

- **普通食品可用表达**：夜间轻负担、晚间小仪式、温和花果香、低糖软糖、睡前场景友好。
- **不建议/禁用表达**：改善睡眠、治疗失眠、褪黑素软糖、快速入睡、缓解焦虑。
- **需复核**：GABA 使用范围与最大使用量；酸枣仁作为药食同源原料在糖果中的适用性；褪黑素仅作为保健食品原料路径提醒，不应进入普通食品配方草案。

### 供应商匹配思路

- 向 Ingredia/ANG 询问 `Lactium` 的食品应用案例、建议添加范围、热稳定性、标签建议和过敏原资料。
- 若走 GABA 路线，平台暂无明确供应商匹配，需补充 GABA 供应商库并索取新食品原料合规声明。
- 低糖软糖基底、甜味剂和果胶体系目前平台匹配弱，需外部补库或作为“暂无平台匹配”。

### 风险点

- 最大风险是把普通食品写成保健食品功效。
- 低糖软糖口感和水活度控制难度高。
- 乳源肽可能带来过敏原和风味遮蔽问题。

### Next Steps

1. 法规复核 GABA、酸枣仁、酪蛋白水解肽在软糖中的使用边界。
2. 打样两套低糖胶体体系：果胶和明胶/复配胶。
3. 向供应商索取稳定性、规格书、COA、过敏原、标签建议。
4. 市场文案只围绕“夜间场景/轻负担/风味仪式感”做 A/B。

## RC-20260530-002 清爽运动后高蛋白饮

- **状态**：draft
- **质量评分初估**：84/100
- **场景标签**：运动营养、高蛋白、饮料、清爽口感、男性健身
- **目标人群**：健身男性和轻运动用户，运动后需要便捷蛋白补充，但不喜欢厚重奶昔口感。
- **剂型**：即饮高蛋白饮 / 乳清蛋白清爽饮 / 固体冲调饮备选。
- **法规路径**：普通食品优先；蛋白质营养声称需按营养标签法规和实际含量复核。
- **产品定位**：运动后清爽型蛋白补给饮。

### Formula Routes

1. **保守路线：乳清蛋白清爽饮**
   - 核心原料：分离乳清蛋白或热稳定乳清蛋白、酸甜水果风味、稳定剂/酸度调节体系。
   - 平台候选：`GLA-P292 Provon 292`、`WHC-W90I W90I`、`GLA-T690 Thermax 690`。
   - 成本等级：中-高。
   - 工艺注意：酸性饮料中蛋白澄清度、沉淀、热处理稳定性和涩感。

2. **成本路线：WPC + 风味遮蔽**
   - 核心原料：速溶浓缩乳清蛋白粉、柑橘/莓果风味、甜味剂和酸味平衡。
   - 平台候选：`GLA-A282 Avonlac 282`、`WHC-W80I W80I`。
   - 成本等级：中。
   - 工艺注意：WPC 乳感更明显，做“清爽”需控制蛋白浓度、浊度和后味。

3. **创新路线：水解乳清蛋白快速补给**
   - 核心原料：水解乳清蛋白、可选电解质、清爽水果风味。
   - 平台候选：`TAT-HWP117 HWP 117`、`GLA-T690 Thermax 690`。
   - 成本等级：高。
   - 工艺注意：水解苦味遮蔽、消费者对“肽”的理解、成本压力。

### 核心原料与平台匹配

| 原料 | 角色 | 平台匹配 | 法规/边界 | 是否需复核 |
|---|---|---|---|---|
| 分离乳清蛋白 | 高蛋白来源 | Glanbia / Wheyco 多个 WPI | 法规库含乳清蛋白普通食品/保健食品目录边界 | 是 |
| 浓缩乳清蛋白 | 成本友好蛋白 | `GLA-A282`、`WHC-W80I` | 普通食品可作为蛋白来源；不得宣称增强免疫力 | 是 |
| 水解乳清蛋白 | 清爽/消化友好概念 | `TAT-HWP117`、`GLA-T690` | 普通食品表达需保守，避免暗示治疗或特殊功效 | 是 |

### 合规边界

- **普通食品可用表达**：高蛋白、运动后蛋白补充、清爽口感、低脂/低糖（如实达标）、便捷冲调。
- **不建议/禁用表达**：增肌保证、加速恢复、提高睾酮、增强免疫力、治疗肌肉损伤。
- **需复核**：蛋白质含量声称条件；如添加电解质、维生素、矿物质需核对营养强化剂使用范围。

### 供应商匹配思路

- Glanbia/Wheyco/Tatua：索取清爽饮或酸性饮料应用建议、热稳定规格、溶解性、粒径、感官样品。
- 若做即饮，需要供应商提供 UHT/巴氏条件下稳定性案例。
- 风味和稳定体系平台匹配不足，需新增风味/胶体供应商。

### 风险点

- 高蛋白和清爽口感冲突，容易出现沉淀、涩感、粉感。
- 成本路线可能牺牲透明度和清爽感。
- 运动渠道文案容易夸大“恢复/增肌”。

### Next Steps

1. 先打样 WPI 酸性清爽饮和 WPC 低成本饮两套基底。
2. 向供应商要酸性饮料应用配方建议和热处理稳定性。
3. 法规复核高蛋白、低糖、低脂等营养声称门槛。
4. 评估 RTD 与粉剂两种商业化路径的成本差异。

## RC-20260530-003 儿童日常益生菌固体饮料

- **状态**：draft
- **质量评分初估**：76/100
- **场景标签**：儿童、益生菌、固体饮料、家长可理解、普通食品边界
- **目标人群**：3 岁以上儿童家庭，家长关注日常肠道友好和营养支持。
- **剂型**：条包固体饮料 / 可直接入口粉末 / 冲调粉。
- **法规路径**：待确认；菌株和适用人群必须逐株复核。
- **产品定位**：儿童日常肠道友好固体饮，而不是保健食品“调节肠道菌群”。

### Formula Routes

1. **保守路线：益生元 + 温和风味**
   - 核心原料：低聚半乳糖/低聚果糖/膳食纤维、冻干水果粉、温和甜味。
   - 平台候选：`CLA-BGOS Bimuno GOS`。
   - 成本等级：中。
   - 工艺注意：吸潮结块、冲调分散性、儿童接受度。

2. **主流路线：可用于食品菌种 + 益生元**
   - 核心原料：乳双歧杆菌或鼠李糖乳杆菌等可用于食品菌种、GOS/FOS。
   - 平台候选：菌种暂无平台产品匹配；GOS 可匹配 `CLA-BGOS`。
   - 成本等级：中-高。
   - 工艺注意：活菌数衰减、水分活度、包装阻隔、货架期验证。

3. **创新路线：后生元儿童友好粉**
   - 核心原料：后生元/酵母来源原料、益生元、果味粉。
   - 平台候选：`EPC-EPC EpiCor 后生元`（功能联想强，需确认儿童适用和普通食品表达）。
   - 成本等级：高。
   - 工艺注意：原料风味、颜色、儿童适用资料。

### 核心原料与平台匹配

| 原料 | 角色 | 平台匹配 | 法规/边界 | 是否需复核 |
|---|---|---|---|---|
| 低聚半乳糖 GOS | 益生元/口感 | `CLA-BGOS Bimuno GOS` | 法规库已收录新食品原料；需核对使用范围 | 是 |
| 乳双歧杆菌/鼠李糖乳杆菌 | 菌种 | 暂无平台产品匹配 | 法规库有菌种条目；儿童适用需逐株核对 | 是 |
| 后生元/酵母来源原料 | 差异化 | `EPC-EPC EpiCor` | 普通食品不得宣称增强免疫力；儿童适用需供应商资料 | 是 |

### 合规边界

- **普通食品可用表达**：日常肠道友好、膳食纤维补充、好冲调、儿童喜欢的水果风味。
- **不建议/禁用表达**：调节肠道菌群、增强免疫力、治疗便秘/腹泻、改善过敏、提高抵抗力。
- **需复核**：儿童适用年龄；菌株全名和菌株号；活菌添加量与终产品标示；益生元使用量；是否涉及婴幼儿食品限制。

### 供应商匹配思路

- GOS 路线先找 Clasado/ANG 索取儿童食品应用、建议添加量、口感和法规资料。
- 菌种供应商目前平台缺口明显，需要建立菌株级供应商表。
- EpiCor 如用于儿童方向，必须索取儿童适用、安全性和标签建议，不建议作为第一版保守路线。

### 风险点

- 儿童产品监管和舆情敏感度高。
- “益生菌”容易被市场端写成保健食品声称。
- 活菌稳定性和真实终产品活菌数验证成本高。

### Next Steps

1. 法规专家先做菌株和儿童适用清单。
2. 建立菌株级数据字段：菌种、菌株号、可用食品类别、适用人群、供应商。
3. 打样益生元无活菌版本作为低风险路线。
4. 包装重点测试吸潮、结块和活菌衰减。

## RC-20260530-004 银发骨骼营养乳饮

- **状态**：draft
- **质量评分初估**：82/100
- **场景标签**：银发、骨骼营养、乳制品、钙、维生素D、蛋白质
- **目标人群**：50 岁以上中老年人，日常早餐/晚间饮用，关注蛋白和钙摄入。
- **剂型**：调制乳 / 发酵乳 / 乳蛋白营养饮。
- **法规路径**：普通食品优先；营养强化剂和新食品原料需按食品类别复核。
- **产品定位**：高钙高蛋白的银发日常乳营养饮。

### Formula Routes

1. **保守路线：高钙高蛋白调制乳**
   - 核心原料：牛奶蛋白/乳清蛋白、钙源、维生素D。
   - 平台候选：`ING-PM85 Promilk 85`、`GLA-A282 Avonlac 282`、`ARM-CC Calcium Caseinate`。
   - 成本等级：中。
   - 工艺注意：钙盐沉淀、热处理稳定、口感粉感。

2. **主流路线：乳矿物盐 + 维D 协同**
   - 核心原料：乳矿物盐、维生素D、牛奶蛋白。
   - 平台候选：`GLA-TCD7 TruCal D7`、`ARM-VCM10 Vitalarmor Ca M10`。
   - 成本等级：中-高。
   - 工艺注意：乳矿物盐口感、悬浮稳定、法规使用范围。

3. **创新路线：骨骼概念胶原肽乳饮**
   - 核心原料：胶原蛋白肽、乳蛋白、钙/维D。
   - 平台候选：`GEL-FORT Fortibone`（骨骼健康定位强，普通食品表达需非常保守）。
   - 成本等级：高。
   - 工艺注意：胶原肽风味、热稳定、功效文案风险。

### 核心原料与平台匹配

| 原料 | 角色 | 平台匹配 | 法规/边界 | 是否需复核 |
|---|---|---|---|---|
| 乳矿物盐 | 钙来源/乳源矿物 | `GLA-TCD7`、`ARM-VCM10` | 法规库已收录新食品原料；按公告复核 | 是 |
| 维生素D | 营养强化 | 暂无具体产品匹配 | 法规库已收录营养强化剂；按 GB 14880 食品类别复核 | 是 |
| 牛奶蛋白/乳清蛋白 | 蛋白来源 | `ING-PM85`、`GLA-A282` 等 | 普通食品可作蛋白来源；不得宣称保健功能 | 是 |
| 胶原蛋白肽 | 差异化 | `GEL-FORT`、`WEI-N1000` 等 | 普通食品不得宣称增加骨密度/改善关节 | 是 |

### 合规边界

- **普通食品可用表达**：高钙、高蛋白、添加维生素D（如实达标）、适合日常饮用、银发营养补充。
- **不建议/禁用表达**：治疗骨质疏松、增加骨密度、预防骨折、修复关节、改善关节疼痛。
- **需复核**：调制乳/发酵乳中钙和维D强化范围；乳矿物盐公告使用范围；银发人群文案避免疾病联想。

### 供应商匹配思路

- Glanbia/Armor：索取乳矿物盐在乳制品中的分散性、口感、建议添加和法规声明。
- Ingredia/Glanbia/Wheyco：匹配乳蛋白体系，提高蛋白含量与口感。
- Gelita/Weishardt：若走胶原路线，需确认普通食品标签与骨骼方向表达边界。

### 风险点

- 强骨骼方向很容易触碰保健功能或疾病暗示。
- 钙强化可能带来沉淀、砂感和热稳定问题。
- 银发人群可能涉及慢病用药场景，文案需谨慎。

### Next Steps

1. 先做高钙高蛋白基础乳饮打样，再评估乳矿物盐差异化路线。
2. 法规复核 GB 14880 对目标乳制品类别的钙/维D使用量。
3. 进行钙盐沉淀、热处理和货架期稳定测试。
4. 市场表达聚焦“日常营养补充”，不碰骨质疏松/骨密度承诺。

## RC-20260530-005 女性轻美容胶原蛋白饮

- **核心原料**：乳清蛋白、牛奶蛋白、植物蛋白、胶原蛋白可选、燕麦纤维、低糖甜味体系、油脂/保湿体系。
- **合规边界**：可表达“高蛋白、早餐补充、低糖、办公室零食”；禁用“增肌、减脂、代谢提升、健身药效化”。
- **供应商缺口**：蛋白供应商匹配较强，但燕麦纤维未收录；烘焙吸水性、Maillard 褐变和货架期资料需补。
- **Next Steps**：补燕麦纤维、蛋白烘焙规格、保湿/软化体系、甜味体系、货架期和质构老化案例。
