# 知料供应商连续触达与试点转化材料

> 日期：2026-05-30
> 目标：把供应商访谈从“聊概念”推进到“愿意补资料、看线索、讨论付费试点”。
> 核心说法：知料不是广告位，而是把供应商放进食品研发用户的新品方案工作流。

## 1. 供应商侧一句话定位

```text
知料面向食品研发用户生成 Formula Brief；当用户做新品方案时，系统会把合适的原料、供应商资料和询样/报价下一步嵌入方案包。供应商获得的不是泛流量，而是正在做新品的研发线索。
```

## 2. 第一批优先供应商画像

优先找“需要应用场景教育、不是只拼价格”的供应商：

| 优先级 | 类型 | 为什么适合知料 | 可验证线索 |
|---|---|---|---|
| P0 | 益生菌 / 益生元 | 需要菌株证明、应用场景、稳定性数据 | 儿童益生菌、肠道健康、固体饮料 |
| P0 | 蛋白原料 | 配方路线、口感、成本、溶解性强相关 | 运动蛋白饮、高蛋白零食、银发营养 |
| P0 | 膳食纤维 / 控糖原料 | 功能逻辑和普通食品表达边界敏感 | 控糖代餐、低糖饮料、饱腹零食 |
| P1 | 胶体 / 稳定剂 / 甜味体系 | 真实打样依赖应用方案 | 低糖软糖、乳饮、蛋白饮 |
| P1 | 风味 / 香精 | 和剂型、目标人群、渠道表达相关 | 儿童、银发、运动、女性美容 |
| P1 | 营养强化剂 | 法规适用范围和添加量复杂 | 维 D、钙、铁、锌、乳矿物盐 |
| P2 | OEM/ODM 代工厂 | 可把方案包变成打样机会 | 固体饮料、软糖、饮料、乳品 |

第一批可以优先从 ANG / Novosana / Prochin 相关供应链验证，原因是信任成本低、资料容易拿、可以快速形成样例。

## 3. 连续触达节奏

### 第 0 次：朋友介绍 / 熟人铺垫

目的：建立信任，不发长材料。

```text
{介绍人/称呼}，我最近在验证「知料」的供应商侧价值：研发用户生成新品方案时，系统会匹配合适原料和供应商。

想先找几家原料企业聊聊，不是招商，主要验证这类“AI 推荐给正在做新品的研发用户”的线索有没有价值。

你们如果方便，我想约 20 分钟，了解一下现在线索从哪里来、什么样的研发需求才算高质量。
```

### 第 1 次：正式触达

```text
{称呼}你好，我是 Kane，在做食品研发 AI 工作台「知料」。

我们现在验证一个供应商场景：研发用户输入新品想法后，知料会生成配方路线、合规边界和供应商匹配。如果你们的原料适配，会出现在方案包里，并引导用户询样、要规格书或报价。

我想请你帮忙判断：这种线索对原料供应商有没有价值？什么信息才值得你们跟进？

现在还不是正式招商，20 分钟访谈即可。如果合适，也可以把你们 3-5 个重点产品放进第一批试点样例。
```

### 第 2 次：未回复跟进

间隔 2 天。

```text
补充一句，我不是想让你们买平台会员，主要想验证两个很具体的问题：

1. 如果你的产品被推荐给正在做新品方案的研发用户，这是不是比普通广告更有价值？
2. 你们愿不愿意提供规格书、应用方案、认证、样品信息，让 AI 更准确推荐？

如果你觉得不是你负责，也可以帮我指一下谁更适合聊。
```

### 第 3 次：对方有兴趣后发送短材料

```text
我先发你一个非常短的说明，重点不是平台流量，而是“研发工作流里的供应商推荐”。

我们访谈时主要聊：
- 你们现在怎么获客；
- 什么样的研发需求算高质量线索；
- 你们愿意展示哪些产品资料；
- 如果未来有推荐次数、询样/报价线索、趋势报告，什么情况下愿意付费。
```

可附：`docs/growth/partner-one-pager-2026-05-30.md` 的供应商版摘要。

### 第 4 次：访谈后推进资料

```text
今天谢谢你聊。为了验证是否能把你们产品准确匹配进 Formula Brief，我想先收 3-5 个重点产品资料。

不需要很复杂，优先这些：产品名、核心规格、适用剂型、推荐应用场景、可提供的规格书/认证/样品、联系人。

我会先做成内部试点样例，后续给你看它在方案包里如何被推荐，以及用户对这类推荐是否有询样兴趣。
```

### 第 5 次：资料后转试点

```text
你们这几个产品我建议先进入第一批试点供应商。

试点期我们重点验证三件事：
1. 产品资料是否能提升 AI 推荐准确度；
2. 用户看到供应商匹配后，会不会点击/询样/要报价；
3. 未来供应商专业版按 3000 / 8000 / 20000 年费，对应什么服务才合理。

如果你认可，我发一个简单试点确认模板，不涉及复杂合同，先把范围和预期写清楚。
```

## 4. 20 分钟供应商电话脚本

### 0-2 分钟：降低防御

```text
今天不是招商，也不是问你愿不愿意买会员。我想先理解你们真实获客流程，然后请你判断：AI 研发方案里的供应商推荐，是否可能成为一种更精准的线索来源。
```

### 2-8 分钟：问现状

1. 你们主要卖哪些原料？最想推哪 3 个产品？
2. 现在主要从哪里获得客户线索？
3. 一个有效线索通常长什么样？
4. 从第一次沟通到样品/报价/成交，一般怎么走？
5. 当前最贵或最不稳定的获客方式是什么？

### 8-13 分钟：讲场景

```text
假设一个研发用户输入“开发儿童益生菌固体饮料，家长容易理解，但不能踩保健声称风险”。

知料生成方案时，会列出配方路线、合规边界和供应商匹配。如果你们有适配菌株、益生元或固体饮料应用方案，系统会展示匹配原因、产品资料入口和询样/报价下一步。
```

追问：

1. 你觉得这更像广告、黄页，还是销售线索？
2. 你最想知道用户需求里的哪些字段？
3. 哪些信息不应该直接给供应商，避免用户顾虑？
4. 你希望以什么方式跟进：微信、表单、电话、样品申请？

### 13-18 分钟：验证资料和付费

1. 你愿意提供 3-5 个产品资料做试点吗？
2. 哪些资料可以公开展示，哪些只能私下发？
3. 如果每月给你“被推荐次数、点击次数、询样线索、热门需求词”，有价值吗？
4. 3000 / 8000 / 20000 年费分别需要包含什么，你才觉得合理？
5. 如果下个月上线早鸟版，你愿意先付 3000 试一年，还是需要先看到多少线索？

### 18-20 分钟：拿下一步动作

```text
我想把今天的访谈推进成一个小动作。你觉得更适合哪一个：

1. 你先发 3-5 个重点产品资料；
2. 我用一个与你们产品相关的新品场景跑方案给你看；
3. 你介绍负责市场/销售/应用的人一起聊；
4. 我发试点确认模板，你们内部看一下。
```

## 6. 早鸟试点方案草案

### 6.1 免费资料试点

适用：还没看到线索价值，但愿意补资料。

包含：

- 3-5 个产品进入知料试点资料库。
- 在内部演示和用户访谈中展示匹配逻辑。
- 试点结束给一次反馈：被提及场景、用户关注问题、资料缺口。

供应商需要提供：

- 基础产品资料。
- 一个可联系的销售或应用工程师。
- 对推荐效果和线索字段给反馈。

### 6.2 3000 元/年：早鸟基础版

适用：愿意低成本验证。

包含假设：

- 企业资料页。
- 5 个产品资料维护。
- Formula Brief 推荐曝光记录。
- 月度基础报告：推荐次数、热门场景、用户关注问题。
- 线索手动转发或表单汇总。

### 6.3 8000 元/年：增长专业版

适用：有明确获客需求。

包含假设：

- 20 个产品资料维护。
- 优先完善应用场景和规格字段。
- 线索列表：品类、需求摘要、剂型、目标人群、跟进状态。
- 每月 1 次趋势复盘。
- 协助制作 1 个应用方案内容。

### 6.4 20000 元/年：品类增强版

适用：愿意做品类共创。

包含假设：

- 重点品类共创页或解决方案包。
- 产品资料深度结构化。
- 月度趋势报告。
- 试点用户演示优先展示适配资料。
- 共创白皮书 / 应用案例。

## 8. 常见异议处理

### 异议 1：你们现在有多少流量？

回应：

```text
现在不是卖平台流量，所以我不想用流量包装。我们验证的是更早期的研发意图：用户正在生成新品方案时，是否会对匹配到的原料产生询样和资料需求。第一阶段看线索质量，不看泛流量。
```

### 异议 2：我们只对真实询盘感兴趣。

回应：

```text
合理。所以试点不要求你先大投入，我们先用 3-5 个产品验证：什么需求会触发推荐、用户会问什么、什么线索字段对你们有用。如果没有询样兴趣，就不进入付费。
```

### 异议 3：我们资料比较敏感。

回应：

```text
可以分层展示。公开层只展示产品类别、适用场景和联系入口；规格书、报价、配方建议、COA 可以在用户明确询样后再由你们发。
```

### 异议 4：AI 推荐会不会乱推荐？

回应：

```text
这是我们也要验证的重点。知料会显示匹配原因和可信评分，不追求强行推荐。供应商资料越结构化，越能减少乱匹配。你们的应用工程反馈也会帮助我们修正规则。
```

## 9. 30 天供应商小实验

### 输入

- 5 家供应商。
- 每家 3-5 个产品。
- 5 个 golden question 场景 + 5 个用户真实需求。

### 过程

1. 把供应商产品资料结构化。
2. 在 Formula Brief 演示中观察用户是否关注供应商匹配。
3. 记录每次被推荐的产品、匹配原因、用户追问、下一步动作。
4. 每周给供应商一页反馈。

### 输出

- 哪些品类最容易触发供应商线索。
- 用户最想要哪些供应商资料。
- 供应商愿意维护哪些资料。
- 供应商是否接受早鸟年费。

### 成功标准

满足以下任意 3 条即继续推进：

- 5 家中至少 3 家愿意补完整资料。
- 至少 2 家明确想看推荐次数 / 线索字段。
- 至少 1 家愿意付 3000 早鸟或签试点意向。
- 用户演示中至少 5 次主动追问供应商资料、样品或报价。
