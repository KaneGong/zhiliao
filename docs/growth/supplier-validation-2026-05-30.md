# Formula Brief v1 供应商商业验证材料

> 日期：2026-05-30  
> 项目：知料 Formula Brief v1 商业验证  
> 目标：验证原料供应商是否愿意为 AI 推荐曝光、精准研发线索、资料页和趋势报告付费。

## 1. 验证假设

知料的供应商商业化不是传统黄页，也不是简单广告位，而是嵌入研发工作流的“需求触发型推荐”。

### 核心假设

1. 当研发用户生成 Formula Brief 时，被匹配到的原料/供应商具有更高购买意向。
2. 供应商愿意维护产品资料，因为资料会影响 AI 推荐和线索转化。
3. 供应商愿意为三类价值付费：
   - 推荐曝光：在方案包里被看见；
   - 精准线索：知道谁在做什么品类、需要什么原料；
   - 趋势报告：知道市场在问什么、哪些原料被推荐最多。
4. 早期最可卖的不是“广告”，而是“帮供应商进入新品研发早期决策”。

### 90 天要拿到的证据

- 至少 10 个供应商访谈。
- 至少 5 家愿意完善产品资料。
- 至少 3 家愿意进入付费试点或签意向。
- 至少 1 家愿意为 3000-8000 元/年的早鸟版付费，或明确说出付费前需要看到的线索阈值。

## 2. 供应商访谈提纲

> 建议访谈 25-35 分钟。重点是追问真实获客成本、线索质量、成交路径，不要只听“支持你”。

### 2.1 开场

```text
我们在做食品研发 AI 工作台「知料」。研发用户输入新品想法后，系统会生成配方路线、合规边界和供应商匹配。

我今天不是来招商，主要想验证：如果你的原料在用户做新品方案时被推荐，这对你有没有真实商业价值；以及什么样的线索、数据、报告值得你付费。
```

### 2.2 公司与产品背景

1. 你们主要卖哪些原料？核心品类是什么？
2. 客户主要是品牌方、代工厂、经销商，还是配方公司？
3. 单个客户平均采购周期大概多久？从询样到下单通常经历哪些步骤？
4. 你们最希望切入客户的哪个阶段：新品立项、配方打样、替代供应商、量产采购？
5. 哪些产品最需要应用场景教育，而不是简单报价格？

### 2.3 现有获客方式

1. 现在主要从哪里获得线索：展会、老客户转介绍、微信、1688、官网、内容平台、经销商、BD 拜访？
2. 每个月大概新增多少有效线索？其中多少能进入打样/报价？
3. 你们怎么判断一个线索质量高？
4. 当前获客最贵/最难/最不可控的地方是什么？
5. 有没有为展会、平台会员、信息流、行业媒体、代运营付过费？效果如何？

### 2.4 对 AI 推荐场景的反应

展示或口述场景：

```text
一个研发用户输入“开发一款儿童益生菌固体饮料，希望家长容易理解，但不能踩保健声称风险”。知料生成方案时，如果你们有合适菌株、益生元或应用方案，会在 Supplier Matches 里展示：匹配原料、匹配原因、资料入口、询样/报价下一步。
```

追问：

1. 如果你的产品出现在这种方案包里，你觉得它像广告还是像销售线索？
2. 你最希望看到用户需求中的哪些字段？品类、剂型、目标人群、用量、预算、采购阶段、公司类型？
3. 哪些信息必须脱敏，哪些信息可以给供应商？
4. 如果只告诉你“本月被 AI 推荐 50 次”，是否有价值？为什么？
5. 如果告诉你“5 个用户点击查看资料，2 个申请样品”，这个数据是否足够让你继续投入？

### 2.5 产品资料维护意愿

1. 你们是否愿意维护产品资料？谁来维护：销售、市场、应用工程师、老板？
2. 你们愿意提供哪些资料：规格书、应用方案、检测报告、认证、案例、样品政策、最小起订量？
3. 哪些资料可以公开，哪些只能给已确认身份的用户？
4. 如果平台帮你们整理产品页和应用方案，你是否愿意为此付费？
5. 你们更在意展示“企业品牌”，还是展示“某个具体原料适配某类新品”？

### 2.6 线索跟进流程

1. 收到一个研发线索后，你们希望通过什么方式跟进：微信、电话、站内消息、邮件？
2. 你们能接受平台先做线索筛选吗？例如只给通过手机号/企业/需求完整度筛选的线索。
3. 多久内联系线索最合适？
4. 是否需要 CRM 导出或每周线索表？
5. 你们是否愿意反馈线索状态：已联系、已寄样、已报价、已成交、无效？

## 3. 付费验证问题

> 原则：不要问“愿不愿意付费”，要问“什么证据下、哪个预算科目、谁审批、什么时候付”。

### 3.1 预算与决策

1. 你们每年在获客/展会/平台/内容上的预算大概是多少区间？
2. 3000-20000 元/年的工具或平台服务，通常由谁决定？
3. 这笔钱会从市场费、销售费、信息化、会员费还是老板个人判断里出？
4. 决策前你们需要看到什么：线索数量、同行案例、试用期数据、合同发票、老板认可？
5. 如果下个月上线早鸟试点，你们最快什么时候能决定？

### 3.2 价格敏感度

1. 如果一年 3000 元，只提供基础资料页和推荐曝光统计，你会不会觉得太贵/太便宜/合理？
2. 如果一年 8000 元，增加线索查看和月度推荐报告，你需要看到多少有效线索才觉得值？
3. 如果一年 20000 元，增加重点品类优先匹配、趋势报告、应用内容共创和联合案例，你会在哪些情况下考虑？
4. 你更偏好固定年费、按线索付费、年费 + 成功费，还是免费入驻 + 高级服务？
5. 如果现在给你早鸟价，你愿意先付 3000 元试一年，还是必须先跑 1-2 个月数据？

### 3.3 购买信号分级

| 信号 | 说明 | 判断 |
|---|---|---|
| 强信号 | 愿意马上提供资料，愿意签试点/付早鸟费，能说出预算来源 | 优先推进 |
| 中信号 | 愿意完善资料，但要求先看线索数据 | 进入免费试点，设定 30 天指标 |
| 弱信号 | 觉得有意思，但不愿投入资料或时间 | 暂不深追 |
| 负信号 | 只想免费曝光，不认可线索价值 | 不作为早期商业验证对象 |

## 4. 年费档位假设

> 以下是用于访谈验证的假设，不是最终定价。访谈时要观察供应商觉得“贵”的原因：预算不足、价值不清、线索不足、信任不足，还是服务包不匹配。

### 4.1 3000 元/年：试点基础版

**目标供应商：**

- 中小原料商、区域代理、细分品类供应商。
- 愿意先尝试 AI 推荐渠道，但预算谨慎。

**服务假设：**

1. 供应商基础主页。
2. 最多 5 个产品资料页。
3. 产品可进入 AI Supplier Matches 候选池。
4. 月度基础数据：曝光次数、被匹配次数、资料页访问次数。
5. 每月最多查看 3 条脱敏线索摘要。
6. 基础资料整理模板。

**需要验证：**

- 供应商是否认为 3000 元接近“可无脑试”的预算。
- 如果没有明确线索，只给曝光统计是否足够。
- 他们是否愿意花时间补齐资料。

**成功标准：**

- 访谈中至少 2 家表示可以接受 3000 元早鸟版。
- 至少 1 家愿意在 30 天试点后付费。

### 4.2 8000 元/年：增长专业版

**目标供应商：**

- 有明确新品客户开发需求的原料商。
- 希望获取研发线索，不只做品牌展示。

**服务假设：**

1. 基础版全部权益。
2. 最多 20 个产品资料页。
3. 可查看完整合格线索：需求品类、剂型、目标人群、原料需求、采购阶段、联系方式授权状态。
4. 每月供应商推荐报告：被哪些品类匹配、热门需求、竞品原料趋势。
5. 优先完善 3 个重点产品的应用方案展示。
6. 每季度一次线上复盘：线索质量、资料优化、应用场景建议。

**需要验证：**

- 供应商认为一年多少条有效线索能覆盖 8000 元成本。
- “趋势报告”是否被认为有价值，还是只认可线索。
- 是否愿意反馈线索状态，形成闭环数据。

**成功标准：**

- 供应商能清楚说出有效线索单价区间。
- 至少 2 家愿意在看到 10-20 条有效线索后考虑 8000 元版。

### 4.3 20000 元/年：品类增强版

**目标供应商：**

- 有重点产品线推广预算的企业。
- 应用方案复杂、需要教育市场的原料商。
- 愿意和知料共创品类案例或趋势内容。

**服务假设：**

1. 专业版全部权益。
2. 重点品类/应用场景优先匹配实验：例如助眠软糖、儿童益生菌、运动蛋白饮、女性美容饮。
3. 最多 50 个产品资料页。
4. 联合制作 2-4 个应用方案案例，用于平台样例和供应商销售资料。
5. 季度趋势报告：用户需求、热门配方路线、原料关注度、声称风险趋势。
6. 重点线索人工筛选与转交。
7. 可参与平台早期品类数据共建。

**需要验证：**

- 供应商是否愿意为“品类心智 + 趋势洞察 + 内容共创”付费。
- 20000 元是否必须绑定明确线索数量或销售机会。
- 哪些原料类别最适合增强版：益生菌、蛋白、胶原、透明质酸、膳食纤维、营养强化剂等。

**成功标准：**

- 至少 1 家供应商认为 20000 元不是离谱价格，但需要试点数据或联合案例。
- 能明确列出其购买前需要的 3 个证明。

## 5. 线索价值验证方法

### 5.1 定义“有效线索”

早期不要把所有点击都当线索。建议分 5 级：

| 级别 | 行为 | 线索价值 | 是否可收费 |
|---|---|---|---|
| L0 曝光 | 供应商/产品出现在 Formula Brief 中 | 品牌触达 | 不单独收费，只做统计 |
| L1 查看 | 用户点击产品/供应商资料 | 轻兴趣 | 可计入报告，不建议按条收费 |
| L2 收藏/保存 | 用户保存方案，供应商仍在方案中 | 项目潜在线索 | 可作为线索评分 |
| L3 询样/资料 | 用户申请样品、规格书、报价或授权联系方式 | 高意向线索 | 可收费或计入专业版权益 |
| L4 成交反馈 | 供应商确认寄样、报价、试单、采购 | 商业闭环 | 可用于案例和高阶定价 |

### 5.2 每条线索需要记录的字段

```markdown
# 供应商线索记录

- 线索 ID：
- 日期：
- 来源 Formula Brief：
- 用户类型：品牌方 / 代工厂 / 研发个人 / 产品经理 / 其他
- 需求品类：
- 剂型：
- 目标人群：
- 匹配原料：
- 匹配供应商：
- 行为级别：L0 / L1 / L2 / L3 / L4
- 用户是否授权联系方式：是 / 否
- 用户希望动作：看资料 / 要样品 / 要报价 / 要应用方案 / 其他
- 供应商跟进状态：未联系 / 已联系 / 已寄样 / 已报价 / 无效 / 成交
- 供应商反馈质量：高 / 中 / 低
- 备注：
```

### 5.3 验证线索单价

访谈时让供应商给出自己的判断：

1. 一个“明确品类 + 原料需求 + 联系方式授权”的研发线索，对你值多少钱？
2. 一个“已申请样品”的线索，对你值多少钱？
3. 如果一年 8000 元，需要多少条 L3 线索才觉得值？
4. 如果每条 L3 线索单独收费，你能接受 50 / 100 / 300 / 500 元哪档？
5. 如果线索最终成交，你能否接受成功服务费或年度续费涨价？

### 5.4 30 天小实验设计

**目标：** 不先建设复杂后台，用手工记录也要验证供应商是否重视线索。

**实验步骤：**

1. 找 5 家供应商，每家选 3-5 个重点产品。
2. 把产品资料整理进可演示样例或临时匹配表。
3. 用 5 个 golden questions + 真实用户需求生成 Formula Brief。
4. 记录每次供应商出现在方案中的次数。
5. 对愿意试用的用户提供“申请资料/询样”人工入口。
6. 把每周数据发给供应商：曝光、查看、询样、用户反馈。
7. 30 天后问供应商是否愿意付 3000/8000 年费继续。

**30 天报告模板：**

| 供应商 | 产品数 | 曝光 L0 | 查看 L1 | 保存 L2 | 询样/资料 L3 | 有效反馈 | 供应商付费意愿 |
|---|---:|---:|---:|---:|---:|---|---|
|  |  |  |  |  |  |  |  |

### 5.5 判断规则

- 如果供应商只关心“有没有客户电话”，说明趋势报告暂时不是核心卖点。
- 如果供应商愿意主动补资料，说明 AI 推荐入口有吸引力。
- 如果供应商追问“推荐逻辑是否公平”，说明需要建立资料完整度和匹配规则说明。
- 如果供应商愿意看月报但不愿付费，先把报告作为专业版权益，不单独售卖。
- 如果供应商愿意为单条高意向线索付费，后续可测试“年费 + 线索包”。

## 7. Kane 需要补充的信息

1. 第一批可访谈供应商名单，最好按原料类别分组：蛋白、益生菌、胶原、膳食纤维、营养强化剂、植物提取物、乳矿物盐等。
2. 哪些供应商与 Kane 有强关系，可以直接谈付费和试点。
3. 哪些供应商产品资料可以公开进入演示。
4. Kane 对每类供应商年费承受力的行业判断。
5. 供应商最常见客单价、毛利、获客成本的大致区间。
6. 是否允许从 ANG / Novosana / Prochin 相关供应链开始做手工线索实验。
