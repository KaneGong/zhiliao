# 知料商业验证联系人池与排期模板

> 日期：2026-05-30
> 用途：管理 14 天内的访谈对象、触达状态、演示排期和下一步动作。
> 使用方式：可直接复制到飞书表格 / Notion / Excel，也可在本文件持续追加记录。

## 1. 14 天目标

| 指标 | 目标 |
|---|---:|
| 候选联系人池 | 40 人 |
| 完成触达 | 30 人 |
| 约到访谈 / 演示 | 15 场 |
| 完成深访 | 12 场 |
| 拿到真实 / 半真实新品需求 | 5 个 |
| 供应商愿意补产品资料 | 3 家 |
| 转介绍新联系人 | 5 个 |
| 进入付费或试点讨论 | 1-2 家 |

## 3. 状态枚举

| 状态 | 含义 | 下一步 |
|---|---|---|
| 待触达 | 已列入名单，还没发消息 | 选择话术并触达 |
| 已触达 | 已发第一条消息 | 48 小时内跟进 |
| 已回复 | 对方有回应但未约时间 | 推进 20 分钟访谈 |
| 已约访 | 已确定时间 | 访谈前发 One-pager |
| 已演示 | 已看演示或完成访谈 | 10 分钟内填 scorecard |
| 已给需求 | 对方提供真实 / 半真实需求 | 用需求跑 Formula Brief |
| 已转介绍 | 对方给新联系人 | 当天联系新联系人 |
| 已补资料 | 供应商愿意给资料 | 发资料清单 |
| 试点讨论 | 进入早鸟 / 试点意向 | 发试点确认模板 |
| 暂缓 | 不是目标或无下一步 | 不再主动投入 |

## 4. 优先级评分速算

每项 0-2 分，总分 10 分：

| 维度 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 目标匹配 | 非目标 | 间接相关 | 核心目标用户 / 买方 |
| 近期场景 | 无 | 可能有 | 正在做新品 / 正在获客 |
| 专业判断 | 不能判断 | 部分能 | 能直接挑错 |
| 下一步潜力 | 无 | 可反馈 | 可试用 / 付费 / 引荐 |
| 关系强度 | 冷启动 | 弱关系 | 强关系 / 朋友介绍 |

判断：

- 8-10：P0，本周必须约。
- 5-7：P1，作为补充队列。
- 0-4：P2，暂缓或只做冷启动样本。

## 6. 14 天排期建议

### Day 1：建池 + 触达

- 填 40 人候选池。
- 发送 15 条强关系 / 朋友介绍触达。
- 优先约 3 个研发 / 产品，2 个供应商。

### Day 2：补触达 + 定演示

- 再发送 15 条弱关系 / 供应商触达。
- 对 Day 1 未回复者做轻跟进。
- 锁定 5-8 场访谈时间。

### Day 3-7：密集访谈

- 每天至少 2 场：1 场用户侧 + 1 场供应商侧。
- 每场结束立即填 `interview-scorecard-template`。
- 当天推进强信号下一步，不等周末。

### Day 8-10：第二轮试用 / 资料收集

- 对强信号用户跑真实需求。
- 对强信号供应商发资料清单。
- 对产业伙伴请求转介绍。

### Day 11-14：试点收口

- 汇总分数和原话。
- 形成 3 类名单：P0 试点、P1 跟进、暂缓。
- 争取 1-2 个试点意向或早鸟付费讨论。

## 8. 访谈前检查清单

- [ ] 看过对方公司和品类。
- [ ] 选择一个最贴近的演示场景。
- [ ] 准备一个 30 秒开场。
- [ ] 准备三个必须追问的问题。
- [ ] 准备好 One-pager 链接或文本。
- [ ] 明确本次要拿的下一步动作：真实需求 / 资料 / 转介绍 / 试点。

## 9. 访谈后跟进模板

```text
今天谢谢你帮我看知料。为了我记录准确，想确认三点：

1. 你觉得 Formula Brief 里最可能进入真实工作流的是哪一块？
2. 如果让你下周再用一次，还缺什么必须条件？
3. 你更愿意下一步做哪件事：给一个真实需求 / 拉同事一起看 / 介绍一个更适合的人 / 补供应商资料？

我会按你的反馈调整，不会对外引用你的公司信息。
```

## 10. 周末复盘输出

14 天结束后至少输出三张表：

1. **P0 用户试点名单**：愿意给真实需求、再次试用、内部讨论的人。
2. **P0 供应商试点名单**：愿意补资料、看线索、讨论价格的人。
3. **产品/商业假设调整清单**：基于原话和分数，不基于主观感觉。
