# 知料融资准备与投资人策略

> 日期：2026-05-29
> 当前判断：现在可以准备融资叙事和预沟通，但不建议立刻正式融资。

## 1. 当前是否应该融资？

不建议现在马上正式融资。

原因：
- 产品 MVP 已上线，但核心“方案包”价值还没完全跑通
- 用户行为数据不足
- 供应商付费意愿未验证
- 配方案例库和供应商线索闭环尚未形成

但建议现在开始做两件事：

1. 准备投资人材料草案
2. 做产业资源型预沟通

目标不是马上拿钱，而是获取反馈、资源和潜在试点。

## 2. 融资前最低证据

正式融资前，至少拿到以下证据：

### 用户证据

- [ ] 30 个深度访谈
- [ ] 100 个注册用户
- [ ] 20 个 7 日内回访用户
- [ ] 10 个真实保存方案
- [ ] 5 个用户愿意持续试用

### 供应商证据

- [ ] 5 家供应商愿意完善资料
- [ ] 3 家供应商愿意付费或签意向
- [ ] 至少产生 5 条样品/询价线索
- [ ] 供应商认可“AI 推荐曝光数据”有价值

### 产品证据

- [ ] Formula Brief v1 跑通
- [ ] 100 条配方案例库
- [ ] 方案可信评分
- [ ] 供应商匹配与线索记录
- [ ] 导出报告 MVP

### 商业证据

- [ ] 明确第一个付费产品包
- [ ] 明确第一个目标客群
- [ ] 明确单个客户愿付价格区间
- [ ] 至少 1 个企业试点

## 3. 适合找什么投资人？

优先级：

### 第一优先级：产业资源型天使

特点：
- 懂食品、原料、供应链、B2B
- 能介绍供应商、品牌方、工厂
- 能帮助验证需求

比纯财务投资人更适合当前阶段。

### 第二优先级：食品科技 / 消费产业投资人

适合讲：
- 食品创新效率工具
- AI + 食品研发
- 原料供应链数字化
- 新品开发基础设施

### 第三优先级：B2B SaaS 投资人

适合讲：
- 垂直行业 SaaS
- 供应商网络
- 企业研发工作流
- 数据 + AI agent

### 暂不优先：泛 AI 投资人

泛 AI 投资人容易只看模型能力，不一定理解食品行业慢变量和供应商网络价值。

## 4. 融资叙事草案

### 一句话

知料是中国食品研发 AI 工作台，帮助企业从产品想法快速形成合规配方方案，并连接可信原料供应商。

### 问题

中国食品新品研发高度依赖人工经验和分散资料：
- 查原料难
- 查法规慢
- 找供应商靠关系
- 新品方案整理耗时
- 合规风险高

### 解决方案

知料把原料数据、法规边界、配方案例和供应商网络组织成 AI 工作台：

```text
输入新品想法 → 生成配方路线 → 判断合规边界 → 匹配供应商 → 导出方案包
```

### 为什么现在

- AI agent 能处理复杂研发工作流
- 食品健康化、功能化趋势增强
- 标签和声称监管趋严
- 食品研发数据分散，行业缺少智能工作台
- 大平台还没有完成 AI 工作流闭环

### 商业模式

1. 供应商 SaaS / 线索费
2. 企业研发 SaaS
3. 私有知识库 / API
4. 行业数据报告和内容服务

### 护城河

1. 食品原料知识图谱
2. 中国法规可信层
3. 配方案例库
4. 供应商网络
5. 用户研发项目数据
6. 行业 know-how 和工作流沉淀

## 7. 当前阶段怎么和投资人聊

不要说：

> 我现在要融资。

建议说：

> 我在做一个食品研发 AI 工作台，已经有 MVP。现在想找懂食品供应链/食品科技的人聊聊方向，也希望找到第一批试点企业和供应商资源。

这样压力更小，也更容易拿到真实反馈。

## 8. 什么时候正式融资

满足以下任意两条，就可以认真启动：

- 有 3 家供应商愿意付费或签意向
- 有 1 家企业愿意做付费 PoC
- 月活跃研发用户 > 100
- 每周生成方案 > 100
- 有产业投资人主动表达兴趣
- 数据显示供应商线索转化真实存在
