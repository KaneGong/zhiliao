# 知料资源预算与顾问方案

> 日期：2026-05-29
> 目标：在单人 + AI agents 模式下，用最小现金投入完成 90 天验证。

## 1. 总体原则

当前不建议先招全职团队，也不建议大额外包。

正确投入顺序：

```text
专家判断 > 用户访谈 > 数据建设 > 基础工具 > 品牌物料 > 招人/融资
```

Kane 负责行业判断和商业验证；Codex/AI agents 负责执行；外部专家只补关键判断缺口。

## 2. 预算版本

### 极简版：3000-8000 元 / 3 个月

适合：先验证产品闭环，不追求专家背书。

| 项目 | 预算 | 用途 |
|---|---:|---|
| 服务器 / API / 数据库 | 500-1500 | DeepSeek、服务器、数据库、日志 |
| 法规专家按次咨询 | 1000-3000 | 审核心红线和 10 个案例 |
| 食品研发专家按次咨询 | 1000-3000 | 审 10-20 个配方案例 |
| 运营物料 / 演示 | 500-1000 | 演示视频、海报、文档 |

### 稳妥版：1-3 万元 / 3 个月

适合：想更快形成可信样板和供应商验证。

| 项目 | 预算 | 用途 |
|---|---:|---|
| 法规顾问 | 5000-10000 | 每周审查一次风险输出 |
| 研发顾问 | 5000-10000 | 100 条案例库审稿 |
| 数据整理兼职 | 3000-8000 | 原料、法规、案例录入 |
| 设计/演示材料 | 2000-5000 | 招商页、演示视频、路演材料 |
| 工具与基础设施 | 1000-3000 | 数据库、监控、文档工具 |

### 进取版：5-10 万元 / 3-6 个月

不建议现在立刻采用，除非已经有明确企业试点或供应商付费意向。

可能用于：
- 兼职法规负责人
- 兼职食品研发负责人
- BD 试点销售
- 更完整的数据采购
- 行业展会小规模露出

## 3. 当前最该找的 3 类人

### 3.1 食品法规顾问

职责：
- 审普通食品/保健食品/特殊食品边界
- 审高风险声称词
- 审 Formula Brief 的合规模块
- 帮助定义“需人工复核”的触发条件

合作形式：
- 每周 1 次，1-2 小时
- 或按 10 个案例为一组审查

推荐预算：
- 300-1500 元/小时
- 前 90 天总计 3000-10000 元

寻找渠道：
- 食品法规咨询公司朋友
- 食品伙伴网/行业群里的法规从业者
- 曾做注册备案/标签审核的人

### 3.2 食品研发专家

职责：
- 审方案是否能真实打样
- 判断剂型、风味、工艺、成本是否靠谱
- 审配方案例库
- 给出原料协同和应用场景建议

合作形式：
- 按案例审查
- 每周 10 个案例
- 可远程批注文档

推荐预算：
- 300-1000 元/小时
- 前 90 天总计 3000-10000 元

### 3.3 供应商 BD / 行业销售顾问

当前不建议马上招。

先由 Kane 亲自完成前 10-20 个供应商访谈。原因：
- 创始人必须亲自听到付费阻力
- 供应商愿意付费的理由需要你自己判断
- 太早交给 BD 容易只带来“礼貌性兴趣”

等出现以下信号再找 BD：
- 3 家供应商愿意付费或签意向
- 线索功能跑通
- 有明确服务包和价格

## 4. 不建议现在花钱的地方

- 全职工程师：Codex 暂时够用
- 全职设计师：UI 已基本 OK，Huashu/Codex 可支撑
- 大规模广告投放：目标用户窄，先访谈和行业群
- 昂贵数据库：先做垂直样板数据
- 外包整站重构：会拖慢验证
- 大型展会：除非已有明确演示和 BD 目标

## 5. 软件/工具建议

### 立即够用

| 工具 | 用途 | 成本 |
|---|---|---:|
| Codex Desktop | 主开发与文档 | 已有 |
| DeepSeek API | AI 推荐 | 低 |
| 服务器 | 线上运行 | 已有 |
| GitHub | 版本管理 | 低/已有 |
| 本地 JSON | MVP 数据 | 0 |

### 近期可加

| 工具 | 用途 | 成本 |
|---|---|---:|
| PostgreSQL / Supabase / Neon | 用户、方案、线索结构化存储 | 0-200/月 |
| PostHog / Umami | 用户行为分析 | 0-300/月 |
| Sentry | 错误监控 | 0-300/月 |
| xlsx / docx / pptxgenjs | 导出 | 0 |
| Playwright | PDF/浏览器验证 | 0 |

## 6. 硬件建议

当前无需新增硬件。

如果后续需要本地跑模型/向量库，可再考虑：
- Mac mini / Mac Studio
- 云服务器 GPU

但 90 天验证阶段不建议投入 GPU。当前更重要的是数据质量和用户验证。

## 7. 人力配置建议

### 现在：1 人 + AI agents

Kane：
- 战略判断
- 用户访谈
- 行业资源
- 专业审核
- 商业验证

Codex/AI：
- 开发
- 文档
- 数据
- 测试
- 运营材料

### 30 天后：兼职顾问

如果 Formula Brief v1 跑通，增加：
- 法规顾问
- 食品研发顾问

### 90 天后：按证据决定

如果供应商愿意付费：
- 找 BD / 客户成功

如果企业试点推进：
- 找后端/数据工程兼职

如果投资人表达明确兴趣：
- 准备融资材料，而不是先扩团队

## 8. 明早需要决定的问题

1. 你愿意先投入哪个预算版本？极简 / 稳妥 / 进取？
2. 你身边是否有法规顾问和研发顾问候选？
3. 你是否愿意亲自做前 20 个访谈？
4. 是否先不招人，先用 Codex 执行 30 天？
