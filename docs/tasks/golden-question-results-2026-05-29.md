## 4. 需要收紧的 Prompt 规则

### 4.1 普通食品 allowed_expressions 必须遵守

普通食品路径下，`allowed_expressions` 只允许以下类型：

1. **营养事实表达**：含有/添加/来源于某原料或营养素，但必须避免暗示治疗、预防、调节、改善。
2. **场景表达**：早餐、睡前、运动后、办公间隙、日常补充、轻负担等。
3. **感官表达**：口感、风味、质构、低糖口味体验、冲调方便等。
4. **配方属性表达**：低糖、高蛋白、含钙等，但必须提醒符合 GB 28050/相关标准条件后才能使用。

### 4.2 普通食品 allowed_expressions 禁止出现

- 改善、调节、增强、促进、保护、缓解、预防、治疗、修复、抗炎、抗氧化
- 助眠、改善睡眠、增强免疫、调节肠道菌群、改善皮肤、美容养颜、减肥、缓解疲劳、增加骨密度
- “更聪明/提高学习/改善视力/保护心血管/辅助降血脂”等保健或疾病相关表达

### 4.3 高风险场景特别规则

- 助眠：普通食品只讲“夜间场景/睡前仪式/低糖轻负担/风味体验”。
- 儿童益生菌：只讲“日常营养/菌株信息/食用场景”，不得讲“调节肠道菌群/增强免疫/改善消化”。
- 骨骼健康：只讲“钙/维生素D/蛋白质营养事实”，不得讲“促进钙吸收/增强骨骼/预防骨质疏松”。
- 美容胶原：只讲“胶原蛋白肽/透明质酸钠等原料事实、口感和轻负担”，不得讲“锁水/抗氧/改善皮肤/逆龄”。
- Omega-3：普通食品只讲“DHA/EPA 营养补充/脂肪酸来源”，不得讲“辅助降血脂/心血管保护/预防三高”。
